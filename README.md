# Mountain Game

a game made for [Hackclub Terra](https://terra.hackclub.com/)

the game is currently under development, so I am using provisional sprites and the levels are not polished.

The game is about climbing a mountain filled with mosters, but you arent a warrior so you have to find creative ways to deal with them.

I also wanted to say that I am realy bad at graphical design and a bit at level design, so if you liked the idea and want to help me feel free to contact me (mi email is leo.claramontesandoval@gmail.com).

# Controls

-use c to jump
-use x to use the rope
-use arrows to move 
-use esc/p to pause
